## 1. Designing Data-Intensive Applications
*Author: Martin Kleppmann* | **Category:** Distributed Systems

### Core Takeaways
- **Reliability vs Availability:** How fault tolerance differs across hardware, software, and human error vectors.
- **Replication Strategies:** Single-leader vs multi-leader vs leaderless topologies (Dynamo-style).
- **Partitioning / Sharding:** Handling hot spots and rebalancing node clusters without downtime.

```
Replication Topologies:
├── Single-Leader (Simple, synchronous/asynchronous reads)
├── Multi-Leader (High latency multi-datacenter setups)
└── Leaderless (Quorum reads/writes: W + R > N)
```

## 2. Thinking in Systems
*Author: Donella Meadows* | **Category:** Systems Dynamics

### Core Takeaways
- **Feedback Loops:** Balancing loops (stabilizing) vs Reinforcing loops (exponential growth/collapse).
- **Leverage Points:** Places within a complex system where a small shift in one thing can produce big changes in everything.
- **Delays & Latency:** Unrecognized delays in feedback loops frequently cause system oscillations.

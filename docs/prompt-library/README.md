## 🌟 The Site North Star: Explorable Explanations

The primary mission of **ADVANCED ANALYSIS** is:

> **Not passive, old-fashioned text — but living, visual, and deeply interactive education.**
> When a concept is explained in text, the user should *see it happening live in 3D/Canvas*, interact with it directly, and experience scrollytelling where the visuals continuously react to what they are reading.

Every prompt we study and every technique we extract is evaluated through this lens:
* *How can this 3D model, shader, or spring motion be used to illustrate a concept in quantum mechanics, chemistry, or deep tech?*
* *How can the scroll position or user cursor drive a live simulation rather than just eye candy?*
* *How do we make text and visual state inseparable?*

---

## Analysis Framework

Every prompt is dissected across **8 dimensions**:

| # | Dimension | What We Learn & Extract |
|---|-----------|-------------------------|
| 1 | **Architectural Blueprint** | File structure, dependency policy, vanilla constraints, performance budgets |
| 2 | **Visual Language & Design Tokens** | Palettes, typography, HUD brackets, hairline frames, two-tier token hierarchy |
| 3 | **Motion & Physics Recipes** | Spring solvers, dampening, rAF tickers, scroll-driven interpolation |
| 4 | **Layout Patterns & Responsive Strategy** | Sticky stacks, container queries (`cqw`), viewport scaling, mobile transforms |
| 5 | **3D / WebGL / Canvas Techniques** | Three.js shaders, Draco models, normal/depth maps, procedural fields |
| 6 | **Interaction Design** | Cursor physics, reactive hovers, focus states, sound/visual feedback |
| 7 | **Prompt Engineering Patterns** | The meta-level: why the prompt *itself* produces production code without ambiguity |
| 8 | **Educational & Explorable Translation** | **How to adapt this aesthetic to teach complex ideas interactively (scrollytelling, direct manipulation, synchronized diagrams)** |

## How We Apply This Knowledge

1. **Prompt Ingestion:** When a new prompt is shared, we break down its code structure, design tokens, shaders, and prompt syntax.
2. **Concept Mapping:** We map its visual techniques to specific educational modules (e.g. mapping telemetry dials to physics simulations).
3. **Incremental Synthesis:** We extract components (springs, sticky stacks, canvas seams) and transplant them into our live interactive chapters.
